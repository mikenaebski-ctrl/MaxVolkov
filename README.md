# UNIX shell emulator (вариант 6)

Практическая работа по курсу «Конфигурационное управление», РТУ МИРЭА.
Репозиторий: https://github.com/mikenaebski-ctrl/MaxVolkov

## Общее описание

Эмулятор оболочки UNIX-подобной ОС с графическим интерфейсом (tkinter).
Пользователь вводит команды в окне, эмулятор разбирает строку по правилам
кавычек UNIX, выполняет команду и выводит результат в историю окна.
Команды не передаются оболочке реальной ОС.

Работа выполняется по этапам. Сейчас готов **этап 1 (REPL)**:
GUI, парсер с кавычками, обработка ошибок, команды-заглушки `ls`, `cd`
и команда `exit`. Следующие этапы (параметры командной строки, VFS из
ZIP-архива, команды `cat`, `tree`, `whoami`, `mv`) будут добавлены позже.

Требования: Python 3.9 или новее, только стандартная библиотека и tkinter.

## Функции этапа 1

- Графическое окно с историей ввода и вывода, ввод по клавише Enter.
- Заголовок окна содержит имя VFS: `UNIX shell - demo-vfs`.
- Приглашение к вводу: `student@demo-vfs:/$`.
- Парсер понимает одинарные и двойные кавычки, экранирование (`\ `) и
  пустые аргументы, поэтому `cd "My Documents"` передаёт один аргумент.
- Ошибки не завершают приложение: неизвестная команда, неверное число
  аргументов, незакрытая кавычка.

На этапе 1 VFS не загружается, имя `demo-vfs` задано константой в
`src/constants.py`. Настройка имени через параметры появится на этапе 2.

## Команды

| Команда | Аргументы | Результат |
| --- | --- | --- |
| `ls` | любое количество | выводит имя команды и список аргументов |
| `cd` | ноль или один путь | выводит имя команды и список аргументов |
| `exit` | без аргументов | закрывает окно |

`ls` и `cd` пока заглушки: пути не проверяются, текущая папка не меняется.
Пустая строка игнорируется. Имена команд чувствительны к регистру.

## Структура проекта

```
src/
  __main__.py      точка входа (python3 -m src)
  gui.py           окно tkinter: история, строка ввода, Enter
  parser.py        разбор строки с кавычками (shlex)
  shell.py         выполнение команд через словарь COMMANDS
  commands/        функции команд (по одной на команду)
  result.py        результат команды и признак закрытия окна
  errors.py        ожидаемые ошибки команд
  constants.py     именованные настройки
tests/             модульные тесты и проверки ограничений кода
examples/          команды для ручной демонстрации
run.sh, run.bat    запуск на macOS/Linux и на Windows
```

## Запуск

Из корня проекта.

macOS / Linux:

```sh
sh run.sh
```

Windows:

```bat
run.bat
```

Или напрямую: `python3 -B -m src`.

Для запуска нужен tkinter. Проверка:

```sh
python3 -c "import tkinter"
python3 -m tkinter
```

Вторая команда открывает тестовое окно Tk. Если модуля нет, установите
Python с поддержкой Tcl/Tk (например, с python.org).

## Тесты

Сборка не требуется. Запуск тестов из корня проекта:

```sh
python3 -B -m unittest discover -s tests -v
```

Тесты не требуют tkinter и экрана. Они проверяют:

- парсер: кавычки, экранирование, пустые аргументы, незакрытые кавычки;
- оболочку: вывод заглушек, ошибки, восстановление после ошибки, `exit`;
- ограничения кода (`tests/test_quality.py`): длина строк (до 80) и
  функций (до 40), число аргументов (до 7), цикломатическая сложность
  (до 10), docstring, отсутствие чисел в сравнениях, размер файлов.

## Примеры использования

Команды для ручной демонстрации лежат в `examples/stage1.txt`.
Вводить их нужно по одной в окне эмулятора:

```text
student@demo-vfs:/$ ls
ls: []
student@demo-vfs:/$ ls "My Documents" file.txt
ls: ['My Documents', 'file.txt']
student@demo-vfs:/$ ls 'single quoted path'
ls: ['single quoted path']
student@demo-vfs:/$ ls ""
ls: ['']
student@demo-vfs:/$ cd "My Documents"
cd: ['My Documents']
student@demo-vfs:/$ cd ..
cd: ['..']
student@demo-vfs:/$ cd first second
error: cd: expected at most one path
student@demo-vfs:/$ missing
error: missing: command not found
student@demo-vfs:/$ ls "unfinished
error: parse: No closing quotation
student@demo-vfs:/$ exit now
error: exit: expected no arguments
student@demo-vfs:/$ exit
```

После `exit` без аргументов окно закрывается.
